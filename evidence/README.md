# Nexus visual evidence

Runtime evidence is generated by CI and is not checked in as a substitute for a live run. The validator requires installing, interacting, and running desktop captures plus a running MP4 for each of Linux, Windows, web, Android, and iOS. Every PNG must show a desktop-sized frame (at least 1280x720), and the live X11 application window must pass process and `WM_CLASS` checks during capture.

The Linux job uses the installed GNOME Mines Flatpak, official 7-Zip under Wine, real Chromium, and the F-Droid 2048 APK in Android Emulator via scrcpy. No iOS desktop-window bridge for a real third-party IPA is configured in this repository. The former project-authored UIKit demo and simulator-only image generator were removed; until a real bridge is integrated, the all-ecosystem evidence validator correctly fails for missing iOS evidence.

`boot/desktop-boot.png` is a desktop startup reference only and does not count as application evidence.
